## 0.1.0 — source release, 27 October 2026

- Shared deterministic core imported by the existing web scanner.
- Optional BYOK enrichment that cannot change findings or verdict.
- CLI with live stages, JSON, SARIF and documented exit codes.
- Local MCP tools with structured evidence and bounded local paths.
- Stateless remote MCP app with content-only tools and request limits.

This is source availability, not a claim of npm publication, public endpoint availability or marketplace approval.

title: Library API

ESM, Node 20+ and Web API runtimes. Core has no import-time side effects or telemetry. Only OSV receives exact package names and versions. Optional AI is a separate import.

```ts
import { scan } from '@heysalad/shiptested';
const report = await scan({ lockfile: suppliedText }, {
  signal: controller.signal,
  onStage: event => renderStage(event),
});
```

# ShipCheck design system

The source of truth for the selected code-window identity and **Scan. Check. Ship.** slogan lives in `brand-kit/`.

- Open `brand-kit/index.html` locally for icons, message cards and the motion playground.
- `brand-kit/icons/`: 32 original outline icons and an SVG sprite.
- `brand-kit/cards/`: 18 message templates in SVG and PNG.
- `brand-kit/messages.json` and `MESSAGING.txt`: product, social and transactional copy.
- `brand-kit/brand/`: logo variants, app icon and favicon.
- `brand-kit/design-tokens.*`: implementation tokens.
- `brand-kit/ShipCheck-Brand-Guide.pdf`: identity guidance.

The app uses selected identity assets under `public/brand/`. Preserve descriptive statuses and evidence boundaries when integrating copy. Templates do not certify feature availability.

The motion gallery is SVG/CSS. Native Rive files remain to be authored; the production specification is `brand-kit/RIVE-HANDOFF.txt`. No `.riv` file or runtime integration is claimed.

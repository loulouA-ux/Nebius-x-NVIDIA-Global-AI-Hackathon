The final master was encoded at 1920 × 1080, 30 fps, with narration, and runs 165 seconds. Source capture filenames were `04-shiptested-url-to-verified-repair-20261030.mp4`, `05-shiptested-approved-draft-pr-20261030.mp4`, `06-nemotron-nebius-live-20261030.mp4` and `08-nemotron-review-retake-20261030.mp4`. Raw recording files stay outside this repository to keep clones small; the full video is linked on YouTube.

Waits and navigation were shortened for the video. The Nemotron panel was reopened after the live inference request for a readable capture; the result was not fabricated. The GIF is an accelerated montage and is not a real-time timing benchmark. Static alternatives appear above for readers who prefer no animation.

The GitHub account and repository visible in these assets are the demo operator's public identity and synthetic fixture. No API keys, session cookies or private customer data are intentionally included. The promotional cover should never replace the actual screenshots when checking evidence.
